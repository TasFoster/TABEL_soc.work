# Графики

Владелец — профильный агент Sol. Распределение проверок по сотрудникам и датам. Сверяйте график и его печатный вид.

Сначала прочитайте [документацию функции](../../../docs/функции/Графики.md) и карточку текущей задачи в [журнале](../../../docs/ЖУРНАЛ.md). По завершении передайте координатору изменения, подтверждающие проверки и оставшиеся ограничения.
