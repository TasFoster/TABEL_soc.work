# Исправления по обращениям — 1.8.4

Работа выполнена отдельными коммитами; каждый экспортируется отдельным git-патчем.

- Табель: немедленное сохранение отсутствий по постоянному employee_id и месяцу, восстановление и редактор периода. Схема SQLite не менялась; записи используют ключи settings_kv `timesheet_absence:<employee_id>:<year>:<month>`.
- Печать: очищены колонтитулы XLS и выходных ODF/XLSX; табель задаёт Print_Titles (строки 1–20).
- Приложение: скрыты три расчётные колонки, адаптируется ширина ФИО и перенос, подпись после правой таблицы. Добавлен доступ к общему редактору сотрудников с перечитыванием состава.
- Реестр по оплате: отдельная операция замены единственного изменённого номера госдоговора; ручные месяц/год/сумма шапки; пометки пересмотра.
- Старый клиентский лист «деньги» нормализуется в сводку по группам ГОС, первоначальный лист сохраняется как «деньги (исходный)». На трёх образцах после сохранения и загрузки 15/15 связей.
- Услуги-Деньги: нулевые агрегаты очищают старые значения вместо пропуска записи.
- Планы: отделения и кандидаты-сотрудники из общей БД; редактор текста ячеек, шапки и подписи, заслушивания, отпускников и замен. Данные редактируемого плана — reestr_kv `plan_edit:<dept>:<year>:<month>`.

Для ОСОД без оригинального шаблона используется структура №9 с заменой номера и подписи. Формирование запрещено до просмотра/сохранения плана в редакторе: исходного эталона №2 нет. Это поддержка редактируемого плана, а не утверждённый эталон содержания №2.

Не восстановлен удалённый модуль протоколов: его семь требований требуют отдельного решения о восстановлении функции. Письмо «Добавь новые отчёты» не содержит перечня форм. Эти пункты не заявляются выполненными.

Проверки: 14 unit-тестов; сохранение/перезагрузка трёх образцов ODS и связей денег; чтение Print_Titles через xlrd. Windows GUI, многостраничная печать в Office и визуальная читаемость всех реальных ФИО требуют проверки на Windows. Исходники и БД пользователей не перезаписывались.
