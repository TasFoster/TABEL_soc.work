# Дополнение файлов

Владелец — профильный агент Sol. Акты и договоры, именование по получателю, правила дополнения, редактор месячных актов. Проверяйте повторную обработку и печатный вид.

Сначала прочитайте [документацию функции](../../../docs/функции/Дополнение_файлов.md) и карточку текущей задачи в [журнале](../../../docs/ЖУРНАЛ.md). По завершении передайте координатору изменения, подтверждающие проверки и оставшиеся ограничения.
