# Табель

Владелец — профильный агент Sol. Дневные отметки, отсутствия, печать, полумесяцы и корректировки. Для замещений согласуйте источник данных с приложением к табелю.

Сначала прочитайте [документацию функции](../../../docs/функции/Табель.md) и карточку текущей задачи в [журнале](../../../docs/ЖУРНАЛ.md). По завершении передайте координатору изменения, подтверждающие проверки и оставшиеся ограничения.
