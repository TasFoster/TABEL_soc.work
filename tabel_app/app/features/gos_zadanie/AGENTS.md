# Госзадание

Владелец — профильный агент Sol. Фильтрация получателей, показатели и итоги по листам госзадания.

Сначала прочитайте [документацию функции](../../../docs/функции/Госзадание.md) и карточку текущей задачи в [журнале](../../../docs/ЖУРНАЛ.md). По завершении передайте координатору изменения, подтверждающие проверки и оставшиеся ограничения.
