# Протоколы рабочих совещаний

Карточка «Протоколы» доступна в полной и облегчённой сборках. Выберите ОСОД, месяц и год и нажмите «Открыть период». Для нового протокола дата подставляется по последней рабочей среде из производственного календаря. Если в календаре нет выбранного года, окно показывает предупреждение. Дату можно уточнить вручную.

В «Участниках» можно добавлять, изменять и удалять участников, отмечать присутствие и задавать причину отсутствия. Состав берётся из общего справочника. Для ОСОД №5 и №9 карточка доступна и без заполненного справочника, участников можно добавить вручную.

В «Повестке и докладчике» подставляются тема и формулировка из плана методического часа выбранного отделения и месяца. Фамилии сохраняют падеж из исходного плана. При выборе замены ФИО выводится в именительном падеже после «Докладчик». Формулировку плана и решения можно редактировать. Во вкладке «Разное» каждая строка сохраняется отдельно в тексте документа.

«Сохранить черновик» сохраняет поля и список участников для выбранного отделения и периода. «Сформировать ODT» создаёт документ, сохраняет черновик и помещает копию в архив приложения.

`data/methodical_plans.json` содержит планы ОСОД №5 и №9, перенесённые из присланных планов на 2025 год. Годы в формулировках пересчитываются относительно 2025 года. Для остальных отделений используется существующий справочник `data/protokol/plan.json`. Черновики хранятся в `data/protokol/draft_*.json` рядом с программой. Схема SQLite не меняется.

Экспорт сохраняет порядок разделов образцов: заголовок, списки участников, повестка, «Слушали», решения, «Разное», подпись.
