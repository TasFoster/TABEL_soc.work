# Приложение

Владелец — профильный агент Sol. Нагрузка, нормы и распределение замен по периодам и секторам. Проверяйте итог по каждому сотруднику.

Сначала прочитайте [документацию функции](../../../docs/функции/Приложение.md) и карточку текущей задачи в [журнале](../../../docs/ЖУРНАЛ.md). По завершении передайте координатору изменения, подтверждающие проверки и оставшиеся ограничения.
