Версия 1.8.7 — расширенный формат табеля по новому образцу.

Добавлены оклад/ставка, праздничные и ночные дни/часы, сводка причин неявки.
Дробные оклады сохраняются. Ставка и дополнительные показатели вводятся кнопкой
«Ставка, праздничные, ночные…» для выбранного сотрудника и периода.
Пустые значения остаются пустыми. Часы явок рассчитываются по прежним правилам.
Сохранены функции протоколов из версии 1.8.6.
